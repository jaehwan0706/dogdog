# 댕산책 화면 및 이동 기준

## 화면 목록

- Auth: 로그인, 회원가입, 소셜 로그인
- Onboarding: 최초 반려견 등록
- Home: 현재 반려견, 날씨·환경, 산책 시작 CTA, 오늘 활동, 최근 산책, 추천 장소
- Walk: 지도, GPS 경로, 시간, 거리, 페이스, 칼로리, 사진, 일시정지, 종료
- Walk Result: 경로, 요약 지표, 사진, 기록 저장
- Map: 현재 위치, 사진 핀, 친화시설, 카페·식당·동물병원, 필터, 시설 상세 카드
- Course: 맞춤 산책 코스 추천, 거리, 예상 시간, 코스 정보
- Community: 피드, 상세, 작성, 댓글, 좋아요, 산책 친구, 케어 품앗이
- My Page: 사용자·반려견 정보, 반려견 추가·수정, 산책 기록, 게시글, 설정
- Store(후순위): 상품, 상세, 장바구니, 주문·결제

## 하단 탭

기본 방향은 홈 / 지도 / 커뮤니티 / 마켓 / 마이다. 마켓이 MVP에서 제외되는 동안 비활성 또는 제외할 수 있다. 코스는 홈 또는 지도에서 진입하는 방향을 우선 검토한다.

## 권장 구현 순서

Design System → Navigation → Login → Dog Onboarding → Home → Walk → Walk Result → Map → Course → Community → MyPage → Store

현재 저장소에는 Navigation 구현이 없으므로, 라이브러리와 화면 계약을 먼저 정한 뒤 추가한다.
